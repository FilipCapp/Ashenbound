# Ashenbound

A fast-paced 2D fantasy roguelite inspired by *Fury Unleashed*, combining intense run-and-gun combat with a dark fantasy world. Fight through chapters, face dangerous creatures, wield powerful weapons and discover magical abilities as you battle your way through a world consumed by darkness.

Every encounter is a fight for survival.

**Enter the ashes. Break the curse. Become Ashenbound.**

## Run

Double-click `Play-Godot.cmd` to launch the Godot build.
